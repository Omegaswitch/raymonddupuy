## To add it
1. Download the direct file URL above and save it as `book/images/frontispiece.jpg` (verify it is a JPEG, 656 × 898 px).
2. Create `book/images/frontispiece-caption.txt` with one line, e.g.: `Raymond du Puy. Mědirytina Laurenta Carse, kolem 1725 (Wikimedia Commons, volné dílo).`
3. Replace this file's first paragraph with a record of the download date and the file's SHA-256.
4. Run `bash scripts/build.sh`; the build picks the file up automatically (see `scripts/build.sh`, variable `FRONT`).

Add any other image only after reading its file page for author, date and licence, and record it here.
